# قانون کار ایران — نسخهٔ نصب‌شدنی (PWA)

برنامهٔ آفلاین جستجو و پرسش در **قانون کار جمهوری اسلامی ایران** (۲۰۳ ماده)،
با قابلیت **نصب روی گوشی** و اجرا بدون اینترنت.

---

## ⚡ راه‌اندازی روی گیت‌هاب (۵ دقیقه)

### ۱) ساخت مخزن
1. وارد [github.com/new](https://github.com/new) شوید.
2. نام مخزن را مثلاً `labor-law` بگذارید.
3. حالت **Public** را انتخاب کنید (برای Pages رایگان لازم است).
4. **Create repository** را بزنید.

### ۲) آپلود فایل‌ها
همهٔ فایل‌های این پوشه را (به‌صورت مسطح، بدون پوشهٔ والد) آپلود کنید:

```
index.html
manifest.webmanifest
sw.js
.nojekyll
icons/icon-192.png
icons/icon-512.png
icons/icon-maskable-512.png
icons/apple-touch-icon.png
icons/favicon-32.png
icons/favicon-16.png
icons/icon.svg
```

> سریع‌ترین راه: در صفحهٔ مخزن **Add file → Upload files** و سپس کشیدن فایل‌ها
> (پوشهٔ `icons` را هم می‌توانید کامل بکشید و رها کنید).

### ۳) فعال‌کردن Pages
1. **Settings → Pages**
2. در بخش **Build and deployment**، گزینهٔ **Source** را روی `Deploy from a branch` بگذارید.
3. Branch = `main` و پوشه = `/ (root)` → **Save**.
4. یک تا دو دقیقه صبر کنید. آدرس سایت ساخته می‌شود:

```
https://USERNAME.github.io/labor-law/
```

### ۴) نصب روی گوشی
1. همان آدرس را در گوشی باز کنید.
2. نوار «نصب برنامهٔ قانون کار» از پایین صفحه بالا می‌آید → **نصب**.
3. اگر مرورگر پنجرهٔ نصب را نشان نداد، خود برنامه راهنمای گام‌به‌گام می‌دهد:
   - **اندروید (کروم):** منوی سه‌نقطه → `Install app`
   - **آیفون (سافاری):** دکمهٔ اشتراک‌گذاری → `Add to Home Screen`

بعد از نصب، آیکون ترازوی طلایی روی صفحهٔ اصلی گوشی می‌آید و برنامه **کاملاً آفلاین** باز می‌شود.

## 🧩 ساختار فایل‌ها

| فایل | نقش |
|---|---|
| `index.html` | کل برنامه (داده، رابط کاربری و موتور جستجو در یک فایل) |
| `manifest.webmanifest` | هویت برنامه: نام، آیکون‌ها، رنگ‌ها، میان‌برها |
| `sw.js` | Service Worker برای کار آفلاین و به‌روزرسانی |
| `icons/` | آیکون‌ها در همهٔ اندازه‌های لازم |
| `.nojekyll` | جلوگیری از پردازش Jekyll در GitHub Pages |

فایل‌های توسعه (اختیاری، برای آپلود لازم نیستند):
`articles.json` · `_src/` · `start.cmd`

## ✨ امکانات

- **جستجو** در ۲۰۳ ماده؛ بی‌توجه به «ی/ي»، «ک/ك»، نیم‌فاصله، اعراب و ارقام فارسی/لاتین.
- **پرسش از قانون**: پاسخ کوتاه نقل‌شده از متن ماده + ارجاع به شمارهٔ ماده.
- **مرور ۱۲ فصل** و دسترسی مستقیم به هر ماده.
- **نصب روی گوشی** (PWA) با آیکون اختصاصی و اجرای تمام‌صفحه.
- **آفلاین کامل** پس از اولین بازدید.
- حالت روشن/تاریک، چاپ/PDF، میان‌بر `Ctrl+K`.

---

## ⚠️ هشدار حقوقی

این برنامه یک **ابزار کمکی** است، نه مشاورهٔ حقوقی.
پاسخ‌ها فقط از متن قانون کار استخراج می‌شوند و آیین‌نامه‌ها، بخشنامه‌های ادارهٔ کار،
آرای هیئت‌های تشخیص و رویهٔ عملی در آن لحاظ نشده است.
برای پروندهٔ واقعی با کارشناس حقوق کار مشورت کنید.

## 🔧 به‌روزرسانی برنامه

بعد از هر تغییر در `_src/template.html`:

```bash
cd _src
node build-page.js
```

و برای بازسازی کامل داده از منبع:

```bash
cd _src
node build.js
node make-icons.js
node build-page.js
```

سپس `index.html` جدید را روی گیت‌هاب جایگزین کنید.
اگر نسخهٔ کش‌شده در گوشی قدیمی ماند، در `sw.js` مقدار `VERSION` را یک عدد بالا ببرید.
